# bmedicine.net

The website of B Medicine: teaching by Dr Ahmed Alsinbili, and Hub, a Mac app for projects.

`src/` holds the pages; `python3 -B M02_build_bmedicine_site.py` builds them into `site/` and checks the links;
`--serve` previews the site at http://localhost:8642. The `gh-pages` branch holds the built site that GitHub Pages
serves at https://bmedicine.net.
